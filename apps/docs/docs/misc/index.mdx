# @etiennea20/adr-misc

Utilitaires TypeScript partagés entre le front (navigateur) et le back (Node, NestJS). ESM et
CJS, sans API propre à un environnement, sans dépendance React ni NestJS.

```sh
pnpm add @etiennea20/adr-misc dayjs
```

`dayjs` est une peerDependency : votre projet fournit l'instance (et ses plugins).

```ts
import { formatCurrency, groupBy, isSiret, retry } from "@etiennea20/adr-misc";
```

## Principes

- **Un seul point d'entrée** : tout s'importe depuis `@etiennea20/adr-misc`, le tree-shaking
  ne garde que ce que vous utilisez (`sideEffects: false`).
- **Fonctions pures et immuables** : aucun argument n'est modifié.
- **Français par défaut** : locale `fr-FR`, euro, dates `DD/MM/YYYY`, jours fériés français,
  messages d'erreur en français ; tout est surchargeable par option.
- **Testable** : ce qui dépend de l'heure accepte une date de référence, ce qui est aléatoire
  accepte un générateur injecté.
