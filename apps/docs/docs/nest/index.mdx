# @etiennea20/adr-nest

Utilitaires pour applications NestJS (11 ou 12) : méthodes avancées, gestion des droits,
filtrage avancé, export Excel et JSON. Le package est compilé en CommonJS avec les métadonnées
de décorateurs.

```sh
pnpm add @etiennea20/adr-nest
```

peerDependencies (déjà présentes dans une application NestJS) : `@nestjs/common`,
`@nestjs/core`, `reflect-metadata`, `rxjs`.

- **Guides** : cas d'usage complets, avec un exemple d'application fictive.
- **Référence API** : générée depuis le TSDoc du code source.
