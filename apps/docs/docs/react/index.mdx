# @etiennea20/adr-react

Composants et hooks React (≥ 18), classés par catégorie. Chaque page de composant présente une
**démo live** : le code est modifiable et le rendu se met à jour immédiatement.

```sh
pnpm add @etiennea20/adr-react
```

| Import                          | Contenu                                  | À installer en plus              |
| ------------------------------- | ---------------------------------------- | -------------------------------- |
| `@etiennea20/adr-react`         | content-display, form, ui, crud, filters | rien                             |
| `@etiennea20/adr-react/fetch`   | hooks de fetch, Axios, TanStack Query    | `axios`, `@tanstack/react-query` |
| `@etiennea20/adr-react/routing` | utilitaires de routing                   | `react-router`                   |
